# 🖤 Personal Portfolio

A modern and responsive personal portfolio website with a clean **dark monochrome design**. It showcases my profile, technical skills, projects, achievements, and contact information.

## ✨ Features

- 🏠 Welcome / Home section
- 👤 About Me
- 🛠️ Skills
- 📂 Projects
- 🏆 Achievements
- 📩 Contact
- 📸 Personal profile image
- 🔗 Social media links
- 🧭 Top, side, and bottom navigation
- ✨ Smooth scrolling and hover effects
- 📱 Responsive design
- ⬆️ Scroll-to-top button

## 🛠️ Technologies

- HTML5
- CSS3
- JavaScript
- Font Awesome
- Google Fonts
